# Sound effects

- **Synthesised for SlideBook** (no licence restrictions): boing, bonk, buzzer, cartoon-fall, clown-horn, crickets, ding, drum-roll, dun-dun-dun, record-scratch, rimshot, sad-trombone, slide-whistle-down, slide-whistle-up, honk, funny-whistle, wolf-whistle.
- **CC0 (public domain)**: laughter, laughter-big (cut from "Do you remember laughter", [OpenGameArt](https://opengameart.org/content/do-you-remember-laughter)); kids-laughing ([BigSoundBank](https://bigsoundbank.com/rires-d-enfants-s1660.html)).
- **Pixabay** ([Pixabay Content License](https://pixabay.com/service/license-summary/), free for commercial use, no attribution required): error, glitch-1, impact-bass-1, pop, riser, chime, sparkle, ping, whoosh.

Add your own: drop `.mp3`/`.wav` files into `data\sfx` (beside SlideBook.exe). Optional `data\sfx\manifest.json` in the same shape as this folder's names them and says when to use them, so the shorts finder can pick them.
